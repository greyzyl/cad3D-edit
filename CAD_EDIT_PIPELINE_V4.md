# CAD Edit Dataset Pipeline V4

V4 is the conservative structural replacement branch. It replaces one high-confidence existing feature with another feature.

The target task is:

```text
input:  original dimensioned three-view drawings + natural-language replacement instruction
output: edited executable CadQuery code after replacing the target structure
```

`target_code` is generated by deterministic code editing or deterministic CSG composition. MLLM is used only after validation to write the English replacement instruction.

## Scope

Implemented replace edit types:

| edit_type | strategy | notes |
|---|---|---|
| `replace_circular_cutout_with_slot` | delete circular cutout + append slot cutter | reuses V3 circular cutout deletion |
| `replace_loop_holes_with_slots` | delete simple loop holes + append slot cutters | reuses V3 loop-hole deletion |
| `replace_circular_cutout_with_polygonal_cutout` | direct source replacement | `.circle(r)` -> `.polygon(6, r)` inside cut block |
| `replace_polygonal_cutout_with_circular_cutout` | direct source replacement | `.polygon(n, r)` -> conservative `.circle(r_in)` |
| `replace_polygonal_cutout_with_slot` | delete polygonal cutout + append slot cutter | strict placement; many unsafe cases skipped |
| `replace_chamfer_with_fillet` | direct source replacement | `.chamfer(c)` -> `.fillet(c)` |
| `replace_fillet_with_chamfer` | direct source replacement | `.fillet(r)` -> `.chamfer(r)` |

Not implemented:

- arbitrary feature replacement;
- slot-to-hole replacement;
- pocket/boss/pad replacement;
- low-confidence geometry-inferred replacement;
- edited three-view drawing generation.

## Replacement Strategies

V4 uses two deterministic strategies.

### Delete + Add

Used for slot replacements:

1. Reuse a compatible V3 delete candidate.
2. Generate `P_deleted`.
3. Validate delete stage.
4. Estimate the deleted feature region.
5. Append deterministic CSG block for the new feature.
6. Validate final replacement.

### Direct Source Replacement

Used for primitive-compatible replacements:

```python
.circle(r)      -> .polygon(6, r)
.polygon(n, r) -> .circle(r_in)
.chamfer(c)    -> .fillet(c)
.fillet(r)     -> .chamfer(r)
```

Direct replacement is only used when the source span is high-confidence and the edited code validates.

## Candidate Representation

V4 candidates store the old feature, new feature, intermediate code if applicable, and validation metadata.

Example:

```json
{
  "candidate_type": "structural_replace",
  "edit_type": "replace_circular_cutout_with_polygonal_cutout",
  "old_feature": {
    "feature_type": "circular_cutout",
    "radius": 46.0
  },
  "new_feature": {
    "feature_type": "polygonal_cutout",
    "sides": 6,
    "radius": 46.0
  },
  "instruction_hints": {
    "operation": "replace",
    "old_feature_name": "circular cutout",
    "new_feature_name": "hexagonal cutout"
  }
}
```

## Validation

V4 uses type-specific validators.

### Cutout / Slot Replacement

Applies to:

- `replace_circular_cutout_with_slot`;
- `replace_loop_holes_with_slots`;
- `replace_polygonal_cutout_with_slot`;
- `replace_circular_cutout_with_polygonal_cutout`;
- `replace_polygonal_cutout_with_circular_cutout`.

Checks:

- `P0` executes;
- intermediate delete stage executes when applicable;
- `P_replace` executes;
- `P_replace` is non-empty;
- bbox remains stable;
- changed region is local;
- final geometry changes non-trivially;
- final volume direction is not fixed because replacement can add or remove material overall.

### Finishing Replacement

Applies to:

- `replace_chamfer_with_fillet`;
- `replace_fillet_with_chamfer`.

Checks:

- `P0` and `P_replace` execute;
- `P_replace` is non-empty;
- bbox remains stable and does not collapse;
- geometry changes non-trivially;
- volume delta is non-zero.

Finishing replacements do not require a tiny changed-region bbox.

`intermediate_code` is present for delete + add replacements such as circular cutout to slot.

## Stage 2 Instruction Generation

V4 uses `structural_replace` instruction mode.

MLLM instructions must:

- express replace/convert/swap semantics;
- mention both the old and new features;
- include known dimensions when available;
- say unchanged geometry should be preserved;
- avoid pure add-only or delete-only wording;
- avoid code and implementation details.

Examples:

```text
Replace the existing 60 mm diameter circular cutout with a regular hexagonal cutout of the same radius, keeping the rest of the part unchanged.
```

```text
Replace the 10 mm chamfers on all four vertical edges of the part with 10 mm fillets, keeping the rest of the part unchanged.
```

If MLLM output fails validation, the fallback instruction is used and rejected MLLM text is kept for audit.

## Limitations

- Polygon replacements remain intentionally strict.
- Slot replacement is axis-aligned.
- No arbitrary replacement planner.
- No replacement for pockets, bosses, pads, or arbitrary `.cut(...)` blocks.
