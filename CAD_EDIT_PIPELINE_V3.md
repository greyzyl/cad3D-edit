# CAD Edit Dataset Pipeline V3

V3 is the conservative structural delete branch. It removes existing high-confidence local structures from the original CadQuery program.

The target task is:

```text
input:  original dimensioned three-view drawings + natural-language delete instruction
output: edited executable CadQuery code after deleting the target structure
```

`target_code` is generated by deterministic source-span deletion. MLLM is used only after validation to write the English delete instruction.

## Scope

Implemented delete edit types:

| edit_type | source pattern | deterministic operation |
|---|---|---|
| `delete_hole` | high-confidence `.hole(...)` suffix or simple loop-hole block | source-span deletion |
| `delete_circular_cutout` | `.cut(cq.Workplane(...).circle(...).extrude(...))` | delete complete `.cut(...)` span |
| `delete_polygonal_cutout` | `.cut(cq.Workplane(...).polygon(...).extrude(...))` | delete complete `.cut(...)` span |
| `delete_fillet` | high-confidence `.edges(...).fillet(r)` suffix | delete suffix span |
| `delete_chamfer` | high-confidence `.edges(...).chamfer(c)` suffix | delete suffix span |

Not implemented:

- arbitrary geometric feature deletion;
- union plug / fill-hole as the primary delete method;
- delete slot, pocket, boss, or pad;
- replacement logic inside V3.

## Candidate Representation

Delete candidates identify the exact source block to remove.

Example:

```json
{
  "candidate_type": "structural_delete",
  "edit_type": "delete_polygonal_cutout",
  "source_api": "cut_polygon",
  "block_span_start": 120,
  "block_span_end": 188,
  "block_text": ".cut(cq.Workplane(...).polygon(...).extrude(...))",
  "parameters": {
    "sides": 5,
    "radius": 52.0,
    "depth": 40.0
  },
  "expected_effect": {
    "volume": "increase",
    "bbox": "stable",
    "operation": "remove_subtractive_feature"
  }
}
```

Final Stage 1 records store this as `edit_record`.

## Deterministic Code Generation

V3 generates:

```python
target_code = original_code[:block_span_start] + original_code[block_span_end:]
```

The code is not reformatted or rewritten. Only the selected high-confidence block is removed.

For simple loop holes, V3 removes the workplane suffix plus the loop body together so that `result` remains a solid rather than a workplane context.

## Validation

V3 has two validation policies.

### Cutout Deletion

Applies to:

- `delete_hole`;
- `delete_circular_cutout`;
- `delete_polygonal_cutout`.

Checks:

- `P0` executes;
- `P1` executes;
- `P1` is non-empty;
- deleted subtractive feature causes volume increase;
- bbox remains stable;
- changed region is non-empty and not global;
- changed region roughly matches the volume delta.

### Finishing Feature Deletion

Applies to:

- `delete_fillet`;
- `delete_chamfer`.

Checks:

- `P0` executes;
- `P1` executes;
- `P1` is non-empty;
- bbox remains stable and does not collapse;
- geometry changes non-trivially;
- volume delta is non-zero.

Finishing deletes do not require a tiny local changed-region bbox because fillets and chamfers may affect many edges.

## Stage 2 Instruction Generation

V3 uses `structural_delete` instruction mode.

MLLM instructions must:

- express delete/remove/fill/restore semantics;
- mention the removed feature type;
- include known dimensions when available;
- say unchanged geometry should be preserved;
- avoid add or replace semantics;
- avoid code and implementation details.

Examples:

```text
Remove the circular cutout with a diameter of 92 mm, keeping the rest of the part unchanged.
```

```text
Remove the R7 fillets from all four vertical edges of the part, restoring those edges to sharp right angles, keeping the rest of the part unchanged.
```

If MLLM output fails validation, fallback instruction is used and the rejected MLLM text is retained for audit:

```json
{
  "fallback_used": true,
  "quality_reasons": ["instruction missing key dimension 32"],
  "fallback_reason_summary": "Fallback was used because the MLLM instruction omitted a required dimension from the edit record.",
  "rejected_mllm_instruction": "Remove the triangular cutout from the center of the hexagonal prism..."
}
```

## Limitations

- No arbitrary visual feature deletion.
- No plug-based fill strategy as the main method.
- No slot/pocket/boss/pad deletion yet.
- Polygonal and finishing deletes remain intentionally conservative.
